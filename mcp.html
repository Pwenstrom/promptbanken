Använd Promptbanken via öppen MCP

Promptbanken kan användas direkt på webben eller kopplas till ett AI-verktyg via en öppen MCP-server. Servern ger åtkomst till de öppna promptmallarna utan konto, nyckel eller inloggning.

Använd webben först

Gå till app.promptbanken.se.

Där kan du läsa promptarna, kontrollera hur de är uppbyggda och kopiera dem till en vanlig AI-chatt. Det passar bra om du vill testa snabbt, förstå innehållet eller använda en mall manuellt.

Vad MCP gör

MCP står för Model Context Protocol. I praktiken betyder det att ett AI-verktyg kan fråga Promptbanken efter mallar medan du arbetar, i stället för att du själv behöver söka fram och kopiera prompttexten varje gång.

Den öppna servern kan lista, söka och hämta promptmallar från biblioteket. Den tar inte emot dina egna underlag och kräver ingen personlig nyckel.

Serveradress

Använd den här adressen i AI-klienter som stödjer remote MCP:

https://mcp.promptbanken.se/mcp

I klienter som använder en konfigurationsfil kan inställningen ofta se ut ungefär så här:

{
  "mcpServers": {
    "promptbanken": {
      "url": "https://mcp.promptbanken.se/mcp"
    }
  }
}

Vissa klienter har ett grafiskt gränssnitt där du lägger till en ny MCP-server och klistrar in adressen. Om klienten frågar efter autentisering väljer du alternativet för ingen autentisering om det finns.

Be AI-verktyget använda Promptbanken

Lägg gärna in en enkel anvisning i AI-verktygets instruktioner, så att det vet när Promptbanken ska användas.

När jag ber om svenska texter, underlag, mejl, rutiner, checklistor, informationsutskick, FAQ eller beslutsunderlag ska du först kontrollera om Promptbanken har en relevant mall. Om en mall passar ska du använda den och säga vilken mall du valt.

Det gör att man inte behöver skriva “använd Promptbanken” varje gång. Men vill man vara extra tydlig kan man börja chatten med:

  • Promptbanken: gör detta till klarspråk.
  • Använd Promptbanken och skriv ett informationsutskick.
  • Använd Promptbanken. Här är min text. Välj lämplig mall.

Vilken väg passar dig?

Vill du läsa och kopiera manuellt?Använd app.promptbanken.se.
Vill du att AI-verktyget hittar mallar åt dig?Lägg till den öppna MCP-servern i klienten.
Vill du testa utan teknisk inställning?Börja på webben och kopiera prompten manuellt.

Den publika MCP-servern är https://mcp.promptbanken.se/mcp.

Vilka verktyg stödjer MCP?

Jobbar du i VS Code, Cursor, Windsurf, Codex eller Claude Code kan du ofta använda MCP via en remote-server, beroende på verktyg.

Microsoft-delen behöver särskiljas:

Microsoft 365 CopilotMCP blir relevant genom connectors eller motsvarande kopplingar. Ta detta med IT.
Copilot StudioHär bygger man en agent som kan använda en MCP-server som verktyg.
VS Code med GitHub CopilotUtvecklaren kan lägga till Promptbankens remote MCP-server i sina MCP-inställningar.
Visual Studio med CopilotLiknar VS Code-spåret, men är mer kopplat till Visual Studio och kodnära arbete.

Säkerhet

Den öppna MCP-servern behöver ingen nyckel och ska bara användas för att hämta mallar. Tänk ändå på detta:

  • skicka inte personuppgifter eller sekretessnära underlag till externa AI-verktyg
  • kontrollera alltid AI-svar innan de används
  • följ organisationens regler för vilka externa verktyg som får kopplas in

Claude (Claude Desktop / Claude Code)

Claude Desktop läser MCP-servrar från en konfigurationsfil. Öppna Claude → Settings → Developer → Edit Config, och lägg till:

Publik server (standardmallar, snabbast att testa):

{
  "mcpServers": {
    "promptbanken": {
      "url": "https://mcp.promptbanken.se/mcp"
    }
  }
}

Starta om Claude Desktop efter att du sparat filen. I Claude Code fungerar samma mcpServers-block i projektets .claude-konfiguration.

Verktyget list_pro_templates (namnet är historiskt) visar promptbibliotekets öppna mallar med full prompttext för alla — ingen nyckel eller plan krävs.

OpenAI / ChatGPT

I OpenAI-miljöer används remote MCP som ett verktyg eller en anpassad connector när funktionen är aktiverad för kontot eller arbetsytan. Lägg in serveradressen som remote MCP-server:

{
  "type": "mcp",
  "server_label": "promptbanken",
  "server_url": "https://mcp.promptbanken.se/mcp"
}

Har du inte tillgång till remote MCP eller connectors kan du fortfarande använda den enkla vägen: kopiera prompttexten direkt från app.promptbanken.se in i ChatGPT.

Microsoft Copilot Studio

1. Skapa eller öppna en agentI Copilot Studio, gå till din agent (eller skapa en ny).
2. Lägg till verktygUnder "Tools" (Verktyg) → "Add a tool" → "Model Context Protocol".
3. Ange serveradressKlistra in https://mcp.promptbanken.se/mcp som MCP-serverns URL.
4. TestaAnvänd testfönstret i Copilot Studio och be agenten hämta en promptmall, t.ex. klarspråk eller informationsutskick.

Menyerna i Copilot Studio ändras ibland — leta efter "Tools", "Connectors" eller "Model Context Protocol" om stegen ovan inte matchar exakt. Prata med din IT-avdelning innan du kopplar in externa MCP-servrar i en organisationsagent.

Praktisk slutsats

Vill man testa de öppna promptarna som vanlig webbsida är app.promptbanken.se enklast.

Vill man komma igång direkt utan konto är den publika MCP-servern mcp.promptbanken.se/mcp rätt väg — den ger de öppna mallarna.
