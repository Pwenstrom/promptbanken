# Promptbanken – logotyp och appikoner

Färgprofil:
- Civic blue: #0b63ce
- Neutral ink: #1f2937
- Varm accent: #b7791f

## Rekommenderade filer
- `promptbanken-logo-header.png` – logga i vänster sidhuvud.
- `promptbanken-logo-horizontal.png` – generell horisontell logga.
- `favicon.ico` – klassisk favicon med flera storlekar.
- `favicon-16x16.png` och `favicon-32x32.png` – webbläsarflikar.
- `apple-touch-icon.png` – iOS.
- `android-chrome-192x192.png` och `android-chrome-512x512.png` – PWA/app.
- `promptbanken-mark-transparent.png` – frilagd symbol för vidare bearbetning.

## Kommentar
PNG-loggorna har transparent yta utanför själva logotypen. Appikonerna har avsiktligt en ljus, avrundad bakgrund för att fungera stabilt på olika operativsystem och teman.
